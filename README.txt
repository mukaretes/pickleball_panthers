Pickleball Panthers PWA

Fájlok:
- index.html
- manifest.webmanifest
- service-worker.js
- icons/

Telepítés mobilra:
1. Töltsd fel az egész mappát HTTPS-es tárhelyre, például GitHub Pages, SharePoint webes tárhely vagy bármilyen statikus webhost.
2. Android Chrome-ban nyisd meg az index.html URL-jét.
3. Menü: Hozzáadás kezdőképernyőhöz / Install app.

Fontos: service worker miatt a PWA telepítéshez HTTPS vagy localhost kell. File:// alatt az app megnyílik, de nem települ teljes PWA-ként.
