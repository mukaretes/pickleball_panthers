Pickleball Panthers PWA v1.1

Tartalom:
- index.html
- manifest.webmanifest
- service-worker.js
- icons/

Telepítés:
1. Töltsd fel az egész mappát HTTPS-es statikus tárhelyre, például GitHub Pages vagy Netlify.
2. Android Chrome-ban nyisd meg az URL-t.
3. Menü: Install app / Hozzáadás kezdőképernyőhöz.

Fontos: PWA telepítéshez HTTPS vagy localhost kell. File:// alatt az app megnyílhat, de service worker és teljes PWA telepítés nem működik.
